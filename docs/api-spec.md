# API Specification

## Health

- `GET /health`

## Courses

- `GET /api/courses`

## Circuits

- `POST /api/circuits/validate`

- `POST /api/simulations/run`

- `POST /api/ai/debug-code`
- `POST /api/ai/optimize-circuit`

## Progress

- `GET /api/progress/demo`

## Instructor

- `GET /api/instructor/dashboard`
